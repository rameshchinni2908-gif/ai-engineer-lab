# Setup (2 minutes)

1. Create an empty folder: `mkdir ai-engineer-lab && cd ai-engineer-lab && git init`
2. Copy into it: `CLAUDE.md`, the whole `.claude/` folder, and `KICKOFF.md`
3. Start Claude Code in that folder: `claude`
4. Paste the contents of `KICKOFF.md` as your first message.
5. Optional: run `/agents` to confirm the 10 subagents are detected.

Tips
- Run inside a container/VM if you let it run unattended with relaxed permissions.
- If it stops mid-way, say: "Read docs/PROGRESS.md and continue."
- Want to verify before full build? Tell it: "Stop after Wave 1 and show me."
